# Evaluation

## Question
How much route regret can incident-aware rerouting avoid compared with static path selection?

## Metrics
- Travel time
- Delay avoided
- Reroute frequency
- Unreachable-case handling
- Travel-time regret

## Falsification
- A closed road remains in the chosen path.
- Incident penalties do not alter cost.
- No-route cases return a route.
